# Machine Learning Projects

A collection of Machine Learning projects and experiments developed during the later stages of my **Bachelor of Technology (B.Tech.)**.

This repository preserves my early work in **Machine Learning, Data Analysis, and Predictive Modeling**, including projects developed as part of my academic work and machine learning training.

The projects are primarily implemented using **Python and Jupyter Notebook**, with commonly used libraries such as **NumPy, Pandas, Matplotlib, and Scikit-learn**.

---

## Projects

### 🏠 Chennai House Price Prediction

A machine learning project for predicting house prices using a dataset containing housing-related features from Chennai.

The project covers the typical machine learning workflow:

* Data loading and exploration
* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Feature preparation
* Model training
* Prediction and evaluation
* Visualization of results

**Technologies:** Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Scikit-learn

---

### 📉 Customer Churn Prediction

A supervised machine learning project focused on predicting whether a customer is likely to churn based on available customer attributes.

The project explores:

* Data preprocessing
* Exploratory Data Analysis
* Feature preparation
* Classification techniques
* Model training and prediction
* Model evaluation

**Technologies:** Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Scikit-learn

---

### 🚢 Titanic Survivors Prediction

A classic machine learning classification project based on the Titanic dataset.

The project explores passenger information and attempts to predict survival using machine learning techniques.

It includes:

* Data exploration
* Data cleaning
* Feature analysis
* Data visualization
* Classification
* Model training
* Prediction and evaluation

**Technologies:** Python, Jupyter Notebook, Pandas, NumPy, Matplotlib, Scikit-learn
